### [Agentic Enterprise RAG](https://github.com/sadjad6/agentic-enterprise-rag-langgraph)
**Portfolio application / RAG reference architecture**

Document Q&A with LangGraph orchestration, Weaviate hybrid retrieval and local/cloud LLM modes. Includes DE/EN handling, source citations, optional PII masking and token-based cost estimates; these controls do not establish GDPR compliance.

**Technologies:** Python · LangGraph · Weaviate · FastAPI · Ollama · React

### [Predictive Maintenance MLOps](https://github.com/sadjad6/predictive-maintenance-mlops-system)
**Portfolio ML/MLOps prototype · simulated sensor data**

Prefect workflows for data preparation, failure classification and remaining-useful-life modeling, with FastAPI endpoints and a Dash demo. Some serving paths use heuristic fallback predictions; example metrics and business scenarios are not achieved customer results.

**Technologies:** Python · scikit-learn · XGBoost · LightGBM · Prefect · FastAPI · Plotly Dash

### [Agent Evaluation Lab](https://github.com/sadjad6/agent_eval_lab)
**Experimental synthetic-policy evaluation framework**

One-step synthetic environments with a custom PPO-style policy trainer and threshold-based checkpoint evaluation. Includes distribution-shift datasets, seed controls and repeat-run comparisons; label-noise evaluation is only partially integrated.

**Technologies:** Python · PyTorch · NumPy · PyYAML

### [Self-Improving LLM Knowledge Base](https://github.com/sadjad6/self-improving-llm-kb)
**Portfolio retrieval and memory system**

FAISS/BM25 retrieval with Reciprocal Rank Fusion, stored Q&A interactions, summary notes and evaluation utilities. Summaries require manual reindexing; the system does not automatically retrain the model or demonstrate quality gains.

**Technologies:** Python · FAISS · rank-bm25 · sentence-transformers · MLflow

### [Recommendation ML Platform](https://github.com/sadjad6/recsys-ml-platform)
**Recommendation reference architecture · partial service integration**

FastAPI services, Kafka event publishing, Spark streaming code and MLflow model-loading paths. Redis feature persistence, online updates and automated deployment are incomplete; fixed recommendation fallbacks support the demo.

**Technologies:** Python · FastAPI · Kafka · Spark · Redis · MLflow · Kubernetes

### [Open Autonomous Research Lab](https://github.com/sadjad6/open-autonomous-research-lab)
**Experimental research workflow prototype**

A fixed workflow connects specialist components for data preparation, EDA, baseline ML comparison, evaluation summaries and templated reporting. Additional agents, skill packages, MCP and MLflow components are exploratory or not wired into the default workflow.

**Technologies:** Python · FastAPI · pandas · scikit-learn · Streamlit · Docker Compose
